# Project 0 - Template Analysis

## Phase 1: Head Analysis

### External CSS Libraries

- **Google Web Fonts**

  - Saira
  - Used for the fonts and text styling on the website.

  - Provides icons used throughout the website, such as social media, phone, email, and location icons.

  - Provides additional icons used throughout the template.

  - It controls the custom design and appearance of the HighTech template.

## Phase 2: Site Inventory - Top Half

### Topbar

- **Lines:** 38-56
- **Opening Tag:** `<div class="container-fluid bg-dark py-2 d-none d-md-flex">`
- **Power Classes:**
  - `container-fluid` - makes the section full width.
  - `bg-dark` - gives the topbar a dark background.
  - `py-2` - adds vertical padding.
  - `d-none` - hides the topbar by default.
  - `d-md-flex` - displays the topbar as a flex container on medium screens and larger.

### Navbar

- **Lines:** 58-106
- **Opening Tag:** `<div class="container-fluid bg-primary">`
- **Power Classes:**
  - `container-fluid` - makes the navbar section stretch across the full width of the page.
  - `bg-primary` - gives the navbar the primary Bootstrap background color.

### Carousel

- **Lines:** 108-151
- **Opening Tag:** `<div class="container-fluid px-0">`
- **Power Classes:**
  - `container-fluid` - makes the carousel section stretch across the full width of the page.
  - `px-0` - removes the left and right padding so the carousel can extend across the page.
